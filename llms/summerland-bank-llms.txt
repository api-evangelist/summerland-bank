# Summerland Bank

> Summerland Bank is a customer-owned (mutual) APRA-regulated authorised deposit-taking institution (ADI) and certified B Corporation based in Lismore, New South Wales, Australia (formerly Summerland Credit Union; ABN 21 087 650 360, AFSL/ACL 241167). Under Australia's Consumer Data Right (CDR / Open Banking) it is a registered data holder that exposes a live, public, unauthenticated Product Reference Data (PRD) API conforming to the DSB Consumer Data Standards.

## Overview

- Public PRD base URL: https://public.cdr-api.summerland.com.au/cds-au/v1
- Contract: shared DSB "CDR Banking API" (OpenAPI 3.0.3, v1.36.0) — not bank-proprietary
- Public operations (unauthenticated, require `x-v: 5` header): `GET /banking/products`, `GET /banking/products/{productId}`
- Consumer data (accounts/transactions/balances/payees/direct-debits/scheduled-payments): accredited data recipients only, via OAuth2/OIDC/MTLS CDR consent — not an open developer API.

## APIs

- [Summerland Bank CDR Product Reference Data API](https://www.summerland.com.au/services/digital-and-payments/open-banking/): public product, fee, rate, and eligibility data under the CDR.
